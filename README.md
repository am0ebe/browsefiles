# browsefiles (bf) 📘

A terminal file browser for the go/ knowledge base. It walks a list of files by area, searches them, and opens a file in Sublime with one key. Status and plans: [notes.md](notes.md) · [todo_browsefiles.md](todo_browsefiles.md).
